# 駅前歩行の改善・確認記録

## 2026-11-07 公式写真への復帰

駅前ビューアのAI描き直し表示と3棟試作の読込・選択肢を削除し、初期表示を公式写真に戻した。今回のAIストリーミング複製56枚、比較試作画像と関連する配布版ファイルは削除した。過去の実験や別ビューアに使われる旧資産・記録は残っており、現行駅前ビューアはそれらを読み込まない。

開発ブラウザで公式写真117棟の読込、歩行モードへの切替、地上からの道路表示を確認。写真比較は公式写真と輪郭補正のみ。JS構文検査と配布ファイルのSHA確認は成功。Pythonの全テストはPillow不足による5モジュール読込エラーのため未完了。駅前全域の連続歩行と基準PCの性能は未検証。

## 2026-11-07 駅前道路と歩行の追加変更

- 駅前の公式道路外形とOSM由来の推定路面を表示中の地形に合わせ、公式道路区域にも生成した舗装の質感を適用。駅前の緑色の地表は灰色の仮地表に変更。実路面高・実際の舗装や歩道の位置ではない。
- 推定幅に沿った道路端の目安線、車線数タグが2以上の双方向道路の中央に短い目安線を追加。いずれも実際の白線・車線境界ではなく、画面の「道路の目安線（推定）」で切替可能。歩行者道路の明色舗装はOSMの道路種別を使い、歩道全域の位置を示すものではない。
- 地上視点は道路線分の中央から始め、通常歩行を2.6m/s、Shift併用を3.51m/sに変更。建物壁の近接レイに加え、対象地点の上に建物の屋根がある場合の侵入を防ぐ近似を追加。別メッシュの屋根も検出するが、屋根がない、穴がある、未読込の建物など完全な侵入防止は保証できない。
- 駅前の公式写真は元JPEGの近距離ストリーミングを維持。標準画質では近景の低解像度写真にも最大8倍の異方性を使用し、鮮明化の初期設定を1.5に変更。元画像にない窓や看板は復元しない。
- 合成壁・建物・独立した屋根の衝突テスト、JavaScript構文、実地形の補間検証を実施。Python 3.15の全テストはPillow不足で5モジュール読込不可。基準PCの性能・駅前の現地照合・全ての建物での侵入防止は未検証。
- 開発環境のアプリ内ブラウザ（950×720描画バッファ）で駅前写真117棟の読み込みと歩行ボタンによる地上視点への切替を確認。同一の開始視点で、車道の推定路面、端の推定線、両脇の灰色の仮地表が見えることを確認。駅前全域の連続歩行、白線の現地照合や、視点ごとの写真鮮明度の比較は未実施。

## 今回の改善

- 歩行中に写真比較・写真詳細の視点移動・自動道路移動・性能測定へ切り替える際は歩行を終了する。駅前建物の表示を切った場合も歩行を終了する。
- 読み込み前は歩行開始ボタンを無効にする。Shiftキーを歩行中に押した場合も速度切替を受け付ける。
- 壁に対し3つの高さと左右3点から短いレイを送り、材質の表裏を両方検出する。斜めに接近した場合は、壁に沿う移動成分を再検査する。描画用の材質設定は判定直後に復元する。
- 歩行可能区域、欠損・急な地形変化の判定を関数として分離し、境界と異常値を検査する。
- 建物メッシュと地形タイルの境界を保持し、歩行地点付近にあるものだけを衝突・地面の判定対象にする。駅前の対象メッシュは固定配置を前提とし、動的に移動する建物は対象外。
- 写真の試験設定を初期状態で折りたたむ。Low画質では鮮明化を停止し、ページが非表示の間は描画処理を停止する。内部確認用サーバーには受信・送信タイムアウトを設定する。

## 検証結果

- 合成の片面の壁を使ったNode.js検証：表と裏からの衝突、正面停止、斜めの滑り、描画材質設定の復元。これは実際の福島の建物データではない。
- 歩行区域の境界、欠損値、許容範囲内の地形変化、急な段差を検証。`python -m unittest discover -s tests -v` に含める。開発機にNode.jsがない場合は合成壁検証をスキップする。
- 開発ブラウザで駅前117棟の表示、前進、マウスで上を見ても目線高さが変わらないこと、壁面比較への切替時に歩行が終了することを確認。上を向く操作の前後はどちらも71.08341m。コンソール警告・エラーなし。
- 開発ブラウザで15秒の前進中、最適化前の表示値は18.5 FPS / p95 83.3ms、建物の近傍選別後は35.7 FPS / p95 33.4ms、さらに地形の近傍選別後は35.2 FPS / p95 33.4msだった。別タブ・キャッシュ・読み込み状況を固定していない短時間観測であり、厳密な性能比較や基準PCの合格判定ではない。実機・長時間での再測定が必要。
- 配布版のSHA-256検証は再構築後に実行する。

## 残る制約

衝突は複数レイによる近似で、人の体積による完全な衝突判定ではない。メッシュの穴、建物内部、段差、橋・トンネルや駅前全域での通行は未検証。歩行位置はDEM5A地表に合わせており、公式道路外形は車道と歩道を分けていない。道路幅や路面高は測量済みではない。

写真は元画像の解像度と品質が上限で、鮮明化は新しい実在情報を作らない。Intel内蔵GPU・RAM 8GBの対象機での長時間歩行、fps、メモリ、別PCで更新後の起動は未測定。開発PCの観測から基準PCの性能合格は判定しない。
