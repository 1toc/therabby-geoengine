# Phase 6 暫定終了記録（2026-11-02）

## 判断

利用者の「Phase6はひとまず完了でよい」という指示により、現時点のPhase 6作業を**暫定終了**とする。これは作業段階の区切りであり、v1.0の受入合格、外部公開許可、臨床利用の承認ではない。`preview_manifest.json` と測定JSONの `acceptance_complete` / `v1_0_acceptance_complete` は偽のまま維持する。

## 確認済み

- 福島市全域の公式建物近景・遠景、OSM補完建物、DEM5A地形、OSM道路の静的タイルを生成し、全2,161タイルの資産監査を完了。道路・地形の共有境界も検査した。詳細は[実装・受入状況](CITYWIDE_V1_STATUS.md)。
- ローカルThree.jsビューアで地域選択、道路名・座標検索、画質切替、道路追従、読取APIを動作確認。Windows内部確認用パッケージはPython不要で起動し、コピー時のSHA-256検査を備える。
- 1280×720・軽量・前面表示・10分の有効な測定を3回取得。Intel HD Graphics 4000のChromeで平均59.82/59.84 FPS、Intel UHD Graphics A721のEdgeで平均60.02 FPS。各測定でタイル読込失敗0件。測定原文と個別条件は `docs/evidence/` に保存。
- `python -m unittest discover -s tests -v` の全52件成功。出典・加工記録と公開前権利確認を作成。
