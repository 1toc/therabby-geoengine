# v0.3 第1段階：写真1材質の遅延取得

配布版の通常起動後、URLの末尾に `&photo_pilot=1` を追加する。
`viewer/citywide-v1.html?station_lod2=1&photo_pilot=1` が実験入口。
通常の `start_station_lod2.cmd` と300m表示は維持している。

100m境界はEPSG:6677の中心55386.87527250558,194867.2860515836から各50m。
境界線の高さ72mはデバッグ表示用。地上・俯瞰は既存操作を利用し、視点保存・復元はlocalStorageにカメラと注視点を保存する。

既存Low GLBの1材質 `PLATEAU_Photo_a4fdf53b-4765-4cbc-ae1b-` を利用。
形状・UV・元GLBは変更しない。初期画像256×512、接近時の公式JPEG1024×2048、128933 bytes。
元JPEGはHigh GLBからバイト列のまま1枚だけ抽出し、SHA-256を取得時に検証する。
High GLBはブラウザで取得しない。35m以内で取得、55m超でLowへ戻してdispose/bitmap.close。
共有Low画像を変更しないよう高画質は独立Sourceを持つ。取得中は1リクエストに制限し、離脱で中止、失敗はLowを維持して10秒後に再試行する。

開発ブラウザ実測：初期取得0、接近で1、離脱で解放1、再接近で取得2。
WebGLテクスチャ数124→125→124→125、コンソール警告・エラー0。
実通信ResourceTimingとイベントは `evidence/station_photo_pilot_log.json`。
テクスチャ数はGPUメモリ容量ではない。HTTPキャッシュはブラウザ管理であり、disposeはHTTPキャッシュを削除しない。

既存57件と新規1件のunittest、JS構文確認を通過。
未検証：低スペックPC、長時間移動、意図的通信失敗、UVの同一視点画像差分、全117枚の動的運用。
接近ボタンは形状の外接箱に対する診断視点で、道路上または建物外の安全な視点を保証しない。
全117枚へ展開する前に材質共有の対応表、合計画像予算、同時取得上限、退避順序、タイル解放との寿命管理、視点の遮蔽検査を追加する。
